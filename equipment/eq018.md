## Role

> **Accepted** — The Kinetic Tether arranges close-range combat for Onslaught without replacing RAM's Breach route capability.

## Pull behaviour

| Target | Result |
|---|---|
| Valid standard enemy | Pulls the target toward RAM |
| Heavy or protected target | Uses reduced pull or authored resistance |
| Immovable target | Pulls RAM a short combat distance toward it |
| Boss | Uses authored resistance; never guarantees displacement |
| Route barrier or traversal anchor | Invalid target |

The tether cannot cross solid barriers, create optional-route access, or become general grappling traversal.

> **Accepted** — The Kinetic Tether uses a cooldown and no ammunition.
