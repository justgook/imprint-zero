## Purpose

Follow RELAY's recovered access path into Helix's isolated system, recover four compatible Overdrive Imprints through physical crew trials, and reconnect the infrastructure that opens Act II.

| Boundary | Working version |
|---|---|
| Deployment | All four crew members physically deploy in their own Coffins. RELAY / Wire is the primary controlled Character; ROOK / Tactical, VECTOR / Ghost and RAM / Impact take scripted trial turns. |
| Player control | One controlled Character or Mesh Dive board at a time. No free Character switching, companion AI, general party deployment or Specialization selection within the Mission. |
| Trial order | Four mandatory branches, selectable in any order. A branch completes before another begins; none needs another recipient's Overdrive. |
| Discovery | Access → ordinary-kit trial → convergence and memory → trial-only Overdrive → profile validation. Retrieved memories are not recordings of the present trial. |
| Completion | Four validated crew profiles release the core interlock. Core validation commits the collective unlock; four separate Coffins return the crew to the same physical Hub, now HUB1. |

> **Accepted — Physical crew action:** The other three trials are real events in the facility during RELAY's Mesh Dives, not virtual avatars, possession or playable reconstructions of the memories. M05 is the sole whole-crew deployment and scripted control-transfer exception.
