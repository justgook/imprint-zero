## Purpose

Complete four compatibility trials with the assembled crew, introduce RELAY's Mesh Dive board through Overdrive-module access, reveal Overdrive and Imprints, activate the Research Terminal and Blueprint system, and open the transition to Act II.

## Mission structure

RELAY enters the recovered Helix system and may approach the four crew-specific trials in any order. Control transfers are scripted within each trial.

```mermaid
flowchart TD
    Entry[Deploy as RELAY] --> Hub[Compatibility trial junction]
    Hub --> RookAccess[Mesh Dive<br/>ROOK Overdrive module]
    Hub --> VectorAccess[Mesh Dive<br/>VECTOR Overdrive module]
    Hub --> RamAccess[Mesh Dive<br/>RAM Overdrive module]
    Hub --> RelayAccess[Mesh Dive<br/>RELAY Overdrive module]
    RookAccess --> Rook[ROOK trial]
    VectorAccess --> Vector[VECTOR trial]
    RamAccess --> Ram[RAM trial]
    RelayAccess --> Relay[RELAY trial]
    Rook --> Hub
    Vector --> Hub
    Ram --> Hub
    Relay --> Hub
    Hub -->|All four complete| Core[Imprint validation core]
    Core --> Unlock[Overdrive, Imprints, Research Terminal,<br/>and Blueprints activated]
```

RELAY remains at each branch interface long enough to route access into its sealed Overdrive module; successful access transfers control to that module's crew member for the trial.

Each access board uses a fixed authored move budget, requires no combat Access buildup, guarantees a valid starting solution, and permits unlimited short-reset retries. The four order-flexible boards teach self-contained variations rather than a fixed sequence. They contain no Blueprint Fragment nodes and ignore Null Hack Modules and Program Execution.

The validation core recognizes compatibility between the four crew profiles and stored Imprints. This destabilizes the crew's understanding of themselves without establishing whether they are original, copied, reconstructed, manufactured, or composite people.
