## Purpose

Complete four compatibility trials, assemble the full crew, and unlock Imprints as the campaign’s central progression system.

## Mission structure

RELAY enters the recovered Helix system and may approach the four crew-specific trials in any order. Control transfers are scripted within each trial.

```mermaid
flowchart TD
    Entry[Deploy as RELAY] --> Hub[Compatibility trial junction]
    Hub --> Rook[ROOK trial]
    Hub --> Vector[VECTOR trial]
    Hub --> Ram[RAM trial]
    Hub --> Relay[RELAY trial]
    Rook --> Hub
    Vector --> Hub
    Ram --> Hub
    Relay --> Hub
    Hub -->|All four complete| Core[Imprint validation core]
    Core --> Unlock[Overdrive and Imprint systems unlocked]
```
